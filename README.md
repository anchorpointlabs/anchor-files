# Anchor Files (A1–A5)

Distilled files — identity, voice, knowledge — that make any AI instantly competent in your world.

**Tool is replaceable. Files are forever.**

The Anchor Files are the context-engineering layer of the Anchor Point Method. They travel to Claude Projects, Gemini Gems, NotebookLM, AiVatars Knowledge Base, or any system that accepts document grounding.

## The Five Files

| File | Name | What it holds |
|------|------|---------------|
| A1 | Identity | Who you are, voice, non-negotiables, origin story, ethics, audience language |
| A2 | Product Atlas | What you sell, pricing, scope, revenue model, add-ons |
| A3 | Strategies | ICP, positioning, differentiation, messaging pillars, hooks, objection handling |
| A4 | AI Systems | Operating protocol: modes, output contract, tie-breaker rule, tool routing, quality gate |
| A5 | Brand Reference | Visual identity, brand voice, platform rules, proof points, asset library |

## Build Rhythm (5 steps per file)

1. **Distill** — have AI interview you about the file's domain
2. **Write** — review and edit the draft
3. **Upload** — add to your AI's context (NotebookLM, Claude Project, Gemini Gem…)
4. **Query & Verify** — does the AI produce correct, brand-aligned output?
5. **Refine** — update based on what the query revealed

## Distillation

When all five files exist, condense them into one portable `souls.md` — the pocket version an AI can load anywhere.
