# Anchor Files (A1–A5)

Distilled files — identity, voice, knowledge — that make any AI instantly competent in your world.

**Tool is replaceable. Files are forever.**

The Anchor Files are the context layer of **Company OS** — the knowledge files that sit beneath the SOPs and agent skills (see the `agent-skills` repo). They are the context-engineering layer of the Anchor Point Method. They travel: Claude Projects, Gemini Gems, NotebookLM, or any system that accepts document grounding.

## The Five Files

| File | Name | What it holds | Update cadence |
|------|------|---------------|----------------|
| [A1](templates/a1-identity.md) | Identity | Who you are, voice, non-negotiables, origin story, ethics, audience language | Quarterly or on major change |
| [A2](templates/a2-product-atlas.md) | Product Atlas | What you sell, pricing, scope, deliverables, proof points | On offer change |
| [A3](templates/a3-strategies.md) | Strategies | ICP, positioning, messaging pillars, hooks, strategic priority | Quarterly |
| [A4](templates/a4-ai-systems.md) | AI Systems | Tool stack, routing logic, internal AI policy | On tool change |
| [A5](templates/a5-brand-reference.md) | Brand Reference | Colours, fonts, writing style, formatting rules | On rebrand |

## Build Rhythm (5 steps per file)

1. **Distill** — have AI interview you about the file's domain
2. **Write** — review and edit the draft
3. **Upload** — add to your AI's context (NotebookLM, Claude Project, Gemini Gem…)
4. **Query & Verify** — does the AI produce correct, brand-aligned output?
5. **Refine** — update based on what the query revealed

## Distillation

When all five files exist, condense them into one portable `souls.md` — the pocket version an AI can load anywhere. See [distillation-prompts.md](distillation-prompts.md).
